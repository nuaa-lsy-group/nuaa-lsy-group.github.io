- **郑腾鑫陵**

## 1、工作内容

**① TTA 场景下的 OOD 检测。**
**定义：** 在测试时自适应（TTA）场景下，测试数据不仅存在协变量偏移，还存在标签偏移。目标是在这种双重分布偏移下有效区分分布内（ID）与分布外（OOD）样本。

**② TTA 场景下的 GCD。**
**定义：** 在测试时自适应场景下，测试流中同时包含已知类别与未知类别的样本，且存在分布偏移。目标是在适应分布偏移的同时，对已知类别正确分类，并将未知类别样本聚类为有意义的类别（而非简单拒绝）。与 OOD 检测不同，这里的未知样本需要被**组织**，而不是被**丢弃**。

## 2、所遇问题（技术）

在利用高置信度 ID 更新模型的前提下，如何保证模型对 OOD 仍具有高区分性，即损失函数的设计。

**原因：** 模型吸收高置信度 ID 后容易对 ID 产生过度自信。TTA 的典型做法是用熵最小化、伪标签自训练等目标在测试数据上更新模型，这些目标本身就在压低预测熵、抬高 top1 置信度；当更新只由高置信度 ID 驱动时，ID 的 logit 会被进一步推向“尖峰”，置信度整体上移。而基于置信度、能量、margin 的 OOD 评分依赖 ID 与 OOD 分数分布之间存在可分的间隔——ID 置信度被推高后间隔被压缩，若 OOD 也被 TTA 部分“适应”，其置信度同样上移，两类分布重叠，部分 OOD 就会被误判为 ID。

## 3、解决思路

尝试不同方式保证测试集中 ID 与 OOD 的区分，以及如何利用高置信度 ID、如何推远 OOD 数据。

**做法：** 使用 CLIP 根据图文相似度结合 GMM 区分 ID 与 OOD。效果尚可，大部分 ID 与 OOD 可以较好区分，但存在**难例 ID 流向 OOD** 的问题。通过交叉熵损失可以将部分 ID 拉回，但仍难以同时保证对 OOD 的高区分性。为此利用 GMM 将样本划分为三个高斯区域：**可靠 ID、模糊区（难例 ID 与难例 OOD）、可靠 OOD**。

**思考**： 模型预测可以不局限于 top1 的值，还可以结合 margin（top1 − top2）作为软权重辅助 ID/OOD 的区分。margin 本身携带判别信息：ID 样本 logit 分布通常呈尖峰状，top1 与 top2 间隔较大；OOD 样本分布更平坦，间隔较小。这一信号可以用于模型预测结果的校准（ECE），也可以在模糊区内作为额外的置信度依据，帮助判断一个样本更偏向“难例 ID”还是“难例 OOD”。

## 4、已有/预期进展
尝试一维GMM（基于相似度）和二维GMM（基于相似度和margin），在冻结模型权重的情况下，一维GMM比二维效果好，但更新layernorm后，两者效果差不多。初步实现在CIFAR-10C/SVHN超过ROSITA的指标。

①将自己的方法与ROSITA做比较，验证其他数据集下，与ROSITA的效果。

## 一、本周进展

### 基于 SAM 3 的无人机开放词汇语义分割测试时自适应

#### 1. 工作内容

围绕 SAM 3 在遥感场景中的类别混淆和空间预测不稳定问题，完成视觉提示与类别视觉原型的多组对照实验。重点验证实例视觉提示、区域 Mask 引导的特征原型及竞争类别校准机制，并结合相关工作分析方法有效性。进一步设计双头冲突、跨视角一致性和 LoRA 更新轨迹实验，完成第一阶段实验环境与基础验证。

#### 2. 遇到的问题与困难

视觉参考虽然具有一定的类别判别能力，但尚未稳定转化为语义分割性能提升。区域 Mask 原型优于直接使用矩形框，竞争类别信息也能够改善特征匹配，但融合后仍存在正确像素被误修改的问题。原生视觉提示对不同类别的效果差异较大，缺乏可靠的适用性判断机制。

#### 3. 解决思路／需要讨论的点

暂时停止视觉原型融合方面的进一步调参，将研究重点转向 SAM 3 内部的 Semantic/Instance 双头互补性、几何变换一致性及测试时参数更新稳定性。通过受控实验判断这些信号能否有效识别错误预测，并与导师讨论下一阶段的方法创新方向。

#### 4. 已有进度

已完成视觉提示及视觉原型的多轮实验分析，确认参考内容能够影响类别空间响应，但简单融合未取得稳定收益。完成 P6-0 实验基础建设，验证了无标签适应支持域、三步 LoRA 更新与状态恢复、预测缓存复现及评估一致性，目前已具备开展后续双头冲突实验的条件。

### SAM 3 双头可靠性与测试时自适应机制研究

#### 1. 工作内容

采用分阶段实验方式，优先完成双头反事实与错误检测分析，并与 Margin、Entropy 等基础指标进行对照。固定原有 TTA 配置，每次只改变一个实验因素，通过逐类别性能、错误像素覆盖率及整体 mIoU 判断机制价值，再决定是否引入新的可靠性约束。

#### 4. 预期进度

完成双头冲突实验及逐类别分析，明确 Semantic/Instance 分支的优势与局限；根据结果推进跨视角一致性验证，初步判断双头冲突和几何稳定性是否具有独立的错误识别价值，为下一阶段设计可靠性引导的测试时自适应方法提供依据。
