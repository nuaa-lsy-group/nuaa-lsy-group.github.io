## 1、工作内容

**① TTA 场景下的 OOD 检测。**
**定义：** 在测试时自适应（TTA）场景下，测试数据不仅存在协变量偏移，还存在标签偏移。目标是在这种双重分布偏移下有效区分分布内（ID）与分布外（OOD）样本。

**② TTA 场景下的 GCD。**
**定义：** 在测试时自适应场景下，测试流中同时包含已知类别与未知类别的样本，且存在分布偏移。目标是在适应分布偏移的同时，对已知类别正确分类，并将未知类别样本聚类为有意义的类别（而非简单拒绝）。与 OOD 检测不同，这里的未知样本需要被**组织**，而不是被**丢弃**。

## 2、所遇问题（技术）

在利用高置信度 ID 更新模型的前提下，如何保证模型对 OOD 仍具有高区分性，即损失函数的设计。

**原因：** 模型吸收高置信度 ID 后容易对 ID 产生过度自信。TTA 的典型做法是用熵最小化、伪标签自训练等目标在测试数据上更新模型，这些目标本身就在压低预测熵、抬高 top1 置信度；当更新只由高置信度 ID 驱动时，ID 的 logit 会被进一步推向“尖峰”，置信度整体上移。而基于置信度、能量、margin 的 OOD 评分依赖 ID 与 OOD 分数分布之间存在可分的间隔——ID 置信度被推高后间隔被压缩，若 OOD 也被 TTA 部分“适应”，其置信度同样上移，两类分布重叠，部分 OOD 就会被误判为 ID。

## 3、解决思路

尝试不同方式保证测试集中 ID 与 OOD 的区分，以及如何利用高置信度 ID、如何推远 OOD 数据。

**做法：** 使用 CLIP 根据图文相似度结合 GMM 区分 ID 与 OOD。效果尚可，大部分 ID 与 OOD 可以较好区分，但存在**难例 ID 流向 OOD** 的问题。通过交叉熵损失可以将部分 ID 拉回，但仍难以同时保证对 OOD 的高区分性。为此利用 GMM 将样本划分为三个高斯区域：**可靠 ID、模糊区（难例 ID 与难例 OOD）、可靠 OOD**。

**思考**： 模型预测可以不局限于 top1 的值，还可以结合 margin（top1 − top2）作为软权重辅助 ID/OOD 的区分。margin 本身携带判别信息：ID 样本 logit 分布通常呈尖峰状，top1 与 top2 间隔较大；OOD 样本分布更平坦，间隔较小。这一信号可以用于模型预测结果的校准（ECE），也可以在模糊区内作为额外的置信度依据，帮助判断一个样本更偏向“难例 ID”还是“难例 OOD”。

## 一、本周的进展

### 1.工作内容

本周的工作进度是寻找ABL这个研究方向中可以作为后续研究工作的部分，ABL是神经符号推理领域的一种具体的方法，人工智能领域在发展过程中存在两大范式：符号主义和连接主义。

符号主义是将输入信息抽象成具体的符号，然后使用例如谓词逻辑来进行一步一步的推导，最后得出结果，他的优势就是一切都严格按照事先定义好的规则来进行，不会出现错误，也就是逻辑推理能力强，规则性强，可解释性强。但是缺点就是（2）、现实世界中的事物并不是都能很好的抽象成逻辑符号的形式，比如图片这种数据，也就是感知能力比较弱。（2）符号规则往往依赖人工进行编写，而稍微复杂点儿的任务，他的符号规则可能特别多而且繁杂，人工编写的成本大。

连接主义是就是现代的神经网络，他模仿人脑的神经元的连接，通过神经元之间的相互连接，最后从数据中学习到规律，比如训练集中一张图片中如果大量的出现毛发，耳朵，胡须等等的这些特征的时候，训练集往往会说这个图片对应的标签是猫，神经网络会通过学习到这种规律然后预测出一个这个图片最有可能是什么的标签，这种基于数据的模型的有点是他擅长处理像图片、音频这种数据，也就是感知能力比较强，但是他的缺点是（1）神经网络往往是一个黑盒，为什么数据经过这个网络过后，他能预测出这个图片是猫，一般来说只是网络根据以往的数据训练，觉得他最有可能是猫，但是这种充满了不可解释性，然后现在很多需要决策的系统中是不允许出现这种不可解释性的东西的，所以这一块是他的弱点。

神经符号推理的目标就是为了融合这两种模式的优点，比如连接主义擅长感知，可以用他来处理图片、音频这种复杂的数据，而符号主义擅长逻辑推理，怎么结合二者的优点，就是神经符号推理要解决的问题。现有的一些神经符号推理方法主要是利用符号主义作为知识规则，来在训练集数据量少或者说标签不充分的弱监督问题上的研究。这个角度已经有很多的方法了，ABL就是其中之一。

ABL中的思想其实很早就有，他主要使用的是逻辑溯因的这个思想，而他这里的逻辑溯因是基于溯因推理，溯因推理是很早以前就有的概念，比如现在有一个规则库KB，KB中有一条规则：**下雨后的地面会是湿的**。然后我们现在碰到了一个现象也就是我们观察到地面变湿了，那接着我们要寻找一种解释，就是为什么地面变湿了，我们查询规则库发现下雨过后的地面会是湿的，于是这里我们推测出地面变湿了，是因为下雨了。所以溯因推理这里有三个概念：**知识规则、观察现象、候选假设**。也就是我们观察到了一个现象，我们要从知识规则中找到一种可能导致这种现象的原因，这种原因在这里称为候选假设，为什么是候选假设，因为导致地面变湿了的因素不止下雨这一种，也可能是有人往地面上面泼了水，候选结果是有多个的。另外这里很重要的一点是：**溯因推理他只会从知识规则库中找到一条能够解释这个观察现象的候选假设，但是真实情况不一定是他推理出来的假设，他不会关心究竟是什么导致了地面变湿，他只关心从他的规则库里面来说，下雨和泼水会导致地面变湿，于是他返回这两条结果，但是真实情况不一定是这两种，可能实际上是有人把水桶打翻了。**，而逻辑溯因其实就是用一阶谓词逻辑(**FOL**)来描述上述的溯因推理的思想。

**ABL试图把溯因推理的思想应用到弱监督或者半监督领域中**，一般输入数据比如说是一个图片，可能我们只有一部分图片有真实标签，另一部分图片没有真实标签，这是典型的半监督场景。另一种可能是说我们实际上有一个图片，比如说一个 **1 + 2 **的这种手写算式的图片(实际上是两张图片，每个数字分别是一张)，我们只知道这个算式的结果等于三，但是我们没有每个具体的图片的标签，这是典型的弱监督场景。此时传统的深度学习方法就用不上了。在弱监督的这个场景中。溯因学习是这样，它假设感知模型是有一定的能力的，就是模型不是完全什么都不认识，而是说我能认识一部分的图片里面的数字，于是流程是这样的：感知模型先对两个图片进行预测，比如预测结果是 **1 + 1**，可以看到第一张图片他确实识别出来了，但是第二张图片他预测错了，所以他的预测是不准确的，我们把这个阶段预测出来的标签称为伪标签，但是我们事先有一个知识规则库，它里面记录了规则就是这两个数字加起来比如等于3，于是发现了矛盾，于是溯因推理会试图搜索所有可能的满足规则的结果，他这里一般是穷举，比如他会搜索出来：**（0 + 3）、（1 + 2）、（2 + 1）…**，然后可以看到这里面出现了很多个符合规则的候选，他会从中选择一个标签，然后作为监督标签，选择哪个标签作为监督标签的这个过程，叫做最大化一致性。这里有几种策略就是比如适用汉明距离，也就是找一个和感知模型预测出来的**（1 + 1）**的汉明距离最小的标签**ABL-Hamming**，或者说他把候选标签用感知模型预测一下，算下感知模型对每一个的置信度**ABL-conf**,选择置信度最大的。来和前面模型预测出来的伪标签进行交叉熵损失的计算，然后优化感知模型。

从ABL的流程中其实可以发现传统的ABL存在的一些问题：**1.知识规则一般很难获取，怎么降低规则的获取成本呢？已有一篇研究ABL-KG，他研究的是自动从知识图谱中获取FOL规则。2.溯因搜索一般是穷举搜索，如果搜索空间大的话，那搜索会非常耗时，而实际上是只要任务稍微复杂一点点，他的搜索空间就会特别特别大。3.传统的ABL有一个假设实际上，他就是假设感知模型是有一定的能力的，或者说他假设数据集是半监督数据集，他们会先用有细粒度标签的数据进行模型的预训练，然后用这个预训练模型，然后再进行ABL的流程，拿那些只有粗粒度标签的数据集来训练，但是现实世界中的数据并不总是满足他的这种假设。4.最大化一致性计算的时候，传统的ABL，无论是计算汉明距离还是计算置信度，它本质上是依赖感知模型的能力的，但是我们一开始感知模型的能力我们都不知道靠不靠谱，那感知模型如果一开始就选择了一个错的，然后再用这个错的去优化他自己，那感知模型只会越来越错。**

**目前比较关心的是ABL存在的第4点问题：也就是最大化一致性的时候的标签内的选择问题**，在感知模型预测出伪标签过后，溯因推理模块会通过溯因推理来试图找到满足规则的候选标签列表，然后选择感知模型认为最可靠的那个标签作为监督标签来优化感知模型，但是这里有几个问题就是：**1.感知模型一开始自己都不可靠，他给出来的标签预测就一定是正确的吗？溯因推理模块只在乎给出一个能满足规则要求的候选标签，然后再找一个和感知模型更相信的标签。但是这个标签可能是错误的**，用错误的标签训练模型，只会让模型越来越错，所以传统ABL对预训练模型的能力是有一个初始的阈值的，当高于阈值，那ABL会让他越来越好，但是低于阈值的话，ABL只会让这个模型越来越错 **源自GABL（ICJAI 2021）**。这个就是传统的ABL的一个假设，他假设预训练模型是高于这个阈值的，但是实际上不一定，这个问题已经有部分工作了，来自南大的 **A3BL (ICML2024)**，他认为传统的ABL的最大化一致性部分不可靠的原因是：**感知模型觉得候选标签里面哪个更可能是真的，他是有一个排序的，不是说他只相信得分最高的那个，其他候选结果他也有一定的置信度的，而传统的ABL结果是直接取得分最高的那个，这样是不合理的**，所以**A3BL**的思路是说不像传统的ABL那样只取最高的这种硬标签策略，而是说使用软标签，他会对每张图片得出一个这样的，得出一个向量：[0.1 , 0.3 , 0.4 , 0.2]，而不是前面那种说这张图片我就觉得你是2而不是1，他这里看得到他觉得你这个图片为0的概率是0.1，为1的概率是0.3 … 这个软标签其实也就是感知模型觉得这个这个预测结果的置信度是多少，只不过传统的ABL在这一步会直接选择0.4对应的那个标签，而这里是没有强制选，而是把每一个的都列出来了，这样就保留了一部分信息说感知模型也可能觉得这个图片有点像其他的标签而不是只像最相似的那个标签，**他这篇论文其实就只是提出了传统ABL在最大化一致性的选择候选标签的时候的存在的问题，其实做法就是把硬标签换成了软标签，做法其实很简单。**，然后26年，这篇论文的作者又在arxiv上面发了一篇文章为**ACR**，他觉得 **A3BL**也存在一个问题就是他盲目的把所有的候选结果都打上一个权重，然后拿去算 KL 散度，但是有的候选结果实际上是干扰项，所以 **ACR**他采用一种贪心算法从候选列表中选择几个，然后拿去当监督标签算 KL 散度，而不是像 **A3BL** 那样直接全部丢给感知模型去算 KL 散度。

**但是本质上无论是 ACR 还是 A3BL ，我觉得他们都没有解决一个问题，就是传统的ABL会不断的让感知模型学习到倾向于他最开始认为正确的标签，比如一开始模型觉得这个图片是 1 ，那无论采用硬标签直接把他选择成 1，还是通过软标签，软标签中她一样的会是置信度最高的那个，但是如果一开始模型觉得这个图片是 1 的这个结论是错的呢？**，所以造成这些问题的根本原因就是最大化一致性的时候从候选标签中选择的时候，他是依赖于感知模型的初始能力的，这样会导致恶性循环。所以一开始假设这条数据的最终结果是3，这是已知规则，那根据规则我们能筛选出几条候选，这是一条筛选，接着通过感知模型的能力，再次筛选出真正可以拿来作为监督信息的候选。**我觉得可能的方向是如何找到一个不依赖于感知模型的方法，来从候选标签列表中筛选出最合适的标签，从而避免前面的恶性循环，是一个可以探究的问题。这个目前没有人能研究过。**

**但是也有可能说最大化一致性选择的时候就是必须得依赖感知模型呢，如果没有感知模型的话，那彻底的没有了参考，凭什么认为这个标签是可靠的？也就是如果我们不依赖感知模型的话，那再也找不到其他的方式来筛选这个候选集合了，也有这种可能，所以这个方向的可行性仍待探究 …**

  **1. 工作内容**

  基于原有的FedDual，在此基础上研究如何融合数据集本身天然的类别层次结构知识作为先验，以进一步提升在复杂异质性场景下的全局和个性化指标。参考师兄AAAI相关类别层次工作，目前主要的改动思路包含：1）考虑将原本的客户端-服务器双重一致性蒸馏部分融入类层次知识，设计多层边缘蒸馏，因为相较于细类分布而言，教师模型的超类分布更抗噪，因此考虑在server主蒸馏上增加一个对于超类的蒸馏，进行消融后指标略有提升；2）考虑将类别层次知识用于硬标签的修正，改为超类+细类引导的软标签；3）把层次结构融入客户端本地对开集噪声样本的对比学习中，因为原方案的正样本只包含观测标签相同的样本对，考虑把正样本扩展到同一超类下，让同一超类的样本在特征空间上相互聚合，形成粗类层面的表示结构

  复现了FedMIN，该方法考虑的也是闭集+开集混合存在的噪声场景，整体思路是先建模和识别混合噪声，再在聚合时降低噪声客户端的影响；复现后将FedMIN改造到目前我们的场景下，需要进行一些参数的调整和确保公平性的适配

  **2. 预计问题与困难**

  在类层次蒸馏的基础上设计基于类别层次知识的软标签修正，消融后发现个性化指标提升较明显但是全局指标下降显著，分析后考虑是现有的软标签机制会稀释原本干净样本的监督，导致软目标熵增大，使得客户端分类头弥散，从而导致聚合后全局模型性能变差；同时训练初期的教师模型其实细类精度并不是很高，不能用于频繁对干净样本进行标签软化，需要考虑修改目前方案以平衡个性化和全局情况


  **3. 解决思路**
  
  教师模型对于超类的共识更可靠，考虑增加门控机制对样本做筛选，选择教师模型更确信的样本做有限程度的软标签校正；避免对所有样本进行软标签修正，因为学出来模糊的分类头感觉更容易干扰全局聚合
